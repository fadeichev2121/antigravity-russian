# Antigravity на русском — macOS, Windows и Linux

Русский интерфейс **Antigravity Desktop**: окно чатов и менеджера агентов, настройки, подсказки, контекстные и системные меню. Патч изменяет **оригинальное установленное приложение**, сохраняет исходные файлы и поддерживает откат. Отдельную копию приложения создавать не нужно.

**Пакет 2.0.0:** текущая версия **2.19.1** и пять предыдущих релизов: **2.18.1, 2.17.0, 2.16.0, 2.15.1, 2.15.0**. Релизы взяты из [официального каталога](https://antigravity.google/releases) по состоянию на 5 октября 2026 года.

| Система | Архитектуры | Установка приложения |
| --- | --- | --- |
| macOS | Apple Silicon / Intel | `Antigravity.app`, обычно в «Программах» |
| Windows | ARM64 / x64 | Обычная установка официального EXE |
| Linux | ARM64 / x64 | Папка официальной сборки из tar.gz |

Для всех шести версий подготовлены **36 профилей** с контрольными суммами исходных файлов. Запуск, установка и откат нового пакета на этих системах **пока не проверены на практике**. Это поддержка по анализу официальных сборок; пользовательское тестирование остаётся следующим шагом. Отдельная Antigravity IDE в перевод не входит.

## macOS — две команды в Терминале

Полностью закрой Antigravity через **Cmd+Q**, затем выполни:

```bash
curl -fL https://raw.githubusercontent.com/fadeichev2121/antigravity-russian/main/install.sh -o antigravity_ru.sh
bash antigravity_ru.sh
```

Выбери **1 — Установить русский интерфейс** и ответь на вопрос установщика. После завершения открой Antigravity самостоятельно.

**Изменение подписи:** если установлено официальное приложение, его внешняя подпись Google заменяется локальной ad-hoc подписью. Сохраняются исходные разрешения и hardened runtime; добавляется разрешение отключить проверку происхождения загружаемых библиотек. Вложенные библиотеки и их подписи не меняются. Возможны повторный вход и новые системные запросы разрешений. [Описание разрешения Apple](https://developer.apple.com/documentation/bundleresources/entitlements/com.apple.security.cs.disable-library-validation).

Перед первой установкой сохраняется полная копия приложения. Откат возвращает исходные файлы и подпись. Уже имеющаяся локальная ad-hoc подпись также поддерживается. Подписи других разработчиков отклоняются. Установщик показывает изменение подписи и требует явного согласия.

Нужны **Python 3.9+**, штатные `codesign` и `ditto`, место для резервной копии и версия macOS, на которой работает выбранный Antigravity. Запускай меню без `sudo`: если нужны права администратора, установщик запросит их для выбранного действия. Пароль вводится только в Терминале.

Другой путь приложения:

```bash
bash antigravity_ru.sh --app "/путь/Antigravity.app"
```

## Windows — две команды в PowerShell

Полностью выйди из Antigravity и дождись завершения его обновления. Открой **PowerShell**:

```powershell
Invoke-WebRequest https://raw.githubusercontent.com/fadeichev2121/antigravity-russian/main/windows/install.ps1 -OutFile antigravity_ru.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\antigravity_ru.ps1
```

Выбери **1 — Установить русский интерфейс**, затем запусти Antigravity самостоятельно. `ExecutionPolicy Bypass` относится только к этому запуску PowerShell; постоянные настройки системы не меняются.

Нужны **PowerShell 5.1+ и Python 3.9+**. Установщик ищет обычную EXE-установку в реестре и стандартных папках. Если найдено несколько установок или нужная не обнаружена, укажи папку, где находятся `Antigravity.exe` и `resources`:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\antigravity_ru.ps1 -AppPath "C:\путь\Antigravity"
```

Для этих 12 профилей меняется только `resources/app.asar`: **Antigravity.exe остаётся побайтно исходным**, подпись и настройки EXE не меняются. Его контрольная сумма помогает отличить x64 от ARM64 и проверить исходную сборку. MSIX / Microsoft Store / WindowsApps не поддерживаются.

Если появится отказ в доступе к папке приложения, повтори запуск из PowerShell администратора **в том же пользовательском аккаунте**. Установщик сам не повышает права, не завершает процессы и не меняет права доступа к приложению.

## Linux — две команды в терминале

Нужны **Python 3.9+** и распакованная [официальная Linux-сборка](https://antigravity.google/download). Полностью закрой Antigravity.

Если папка приложения находится в `~/Downloads/Antigravity-x64`:

```bash
curl -fL https://raw.githubusercontent.com/fadeichev2121/antigravity-russian/main/linux/install.sh -o antigravity_ru.sh
bash antigravity_ru.sh --app "$HOME/Downloads/Antigravity-x64"
```

Подставь свой путь. Для ARM64 папка обычно называется `Antigravity-arm64`. В указанной папке должны находиться бинарник `antigravity` и `resources/app.asar`. Без `--app` меню использует `/opt/Antigravity`.

Выбери **1 — Установить русский интерфейс**, затем запусти приложение самостоятельно. Изменяется только `resources/app.asar`, бинарник сохраняется. Запускай меню из обычного аккаунта без `sudo`; если приложение принадлежит root, пароль будет запрошен для выбранного действия. При замене файла сохраняются его владелец и права доступа. Сборки сторонних обёрток, Snap, Flatpak и AppImage не поддерживаются этим каталогом.

## Меню, статус и откат

На каждой системе меню выглядит одинаково:

```text
1) Установить русский интерфейс
2) Статус / совместимость
3) Откат
0) Выход
```

| Пункт | Действие |
| --- | --- |
| **1** | Сохранить исходные файлы и установить перевод либо обновить ранее зарегистрированный перевод. |
| **2** | Показать совместимость, состояние и расположение резервной копии. Файлы приложения не изменяются. |
| **3** | Вернуть исходные файлы из резервной копии. |
| **0** | Закрыть меню. |

Закрывай приложение перед установкой, обновлением перевода или откатом. Установщик не завершает процессы принудительно и не запускает приложение после действия.

Действия без выбора пункта меню:

```bash
# macOS
bash antigravity_ru.sh status
bash antigravity_ru.sh restore

# Linux — используй тот же путь, что при установке
bash antigravity_ru.sh status --app "$HOME/Downloads/Antigravity-x64"
bash antigravity_ru.sh restore --app "$HOME/Downloads/Antigravity-x64"
```

```powershell
# Windows; добавь тот же -AppPath, если указывал его при установке
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\antigravity_ru.ps1 status
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\antigravity_ru.ps1 restore
```

| Система | Состояние и резервные копии |
| --- | --- |
| macOS | `~/Library/Application Support/antigravity-russian/state` |
| Windows | `%LOCALAPPDATA%\antigravity-russian\state` |
| Linux | `~/.local/state/antigravity-russian` |

Не удаляй папку состояния, пока нужен автоматический откат. Для нескольких отдельных установок используй отдельные папки: `--state-dir` на macOS/Linux или `-StateDirectory` в Windows. Профиль пользователя и диалоги установщик не удаляет. Резервные копии после отката сохраняются.

## Обновления и совместимость

**Обновить перевод:** выйди из старого меню пунктом **0**, заново выполни обе команды для своей системы и выбери **1**. Зарегистрированный патч пересобирается из проверенной исходной копии. Снимать перевод перед обновлением его словаря не нужно. macOS-установки пакетов 1.0.x / 1.1.0 сохраняют свои исходные резервные копии.

**Antigravity обновился:** перевод может исчезнуть. Если установлены полностью исходные файлы одной из шести поддерживаемых сборок, пункт **1** создаст новую резервную копию и применит перевод. Старые копии остаются на диске. Откат после этого относится к последней установке патча. Автоматической фоновой русификации нет.

**Неизвестная версия или изменённые файлы:** номер версии и SHA-256 проверяются вместе. Одна и та же версия может иметь другую сборку; при несовпадении установка останавливается. Windows дополнительно проверяет EXE. Старый откат также не применяется поверх файлов новой версии. Не отключай проверку контрольных сумм.

**Прерванная операция:** исходные резервные файлы сохраняются. Для Windows/Linux выбери откат с теми же путями. На macOS штатная ошибка вызывает восстановление файлов до начала действия; после жёсткого прерывания процесса может потребоваться ручное восстановление из сохранённой копии. Не удаляй состояние или резервные файлы.

**Ранний незарегистрированный локальный перевод 2.19.1:** macOS-установщик распознаёт его точный известный архив, сообщает, что перевод уже установлен, и не создаёт фиктивную резервную копию. Для обновления или отката этой ранней установки сначала восстанови оригинал из копии того раннего установщика. Другие изменённые архивы не принимаются.

## Что переводится

Словарь содержит **1193 записи**: настройки, кнопки, подсказки, списки, меню диалога и разделения окна, каталог плагинов Google, отметки времени, системные меню. Новые серверные строки и экспериментальные экраны могут оставаться на английском.

Сообщения, код, редактируемые поля и пользовательские названия исключены из перевода. Ответы модели настраиваются отдельно. Переводчик работает с локальным словарём без отправки данных сервису машинного перевода. Названия моделей и сервисов сохраняются. Патч не изменяет подписку, доступ к моделям или сетевую конфигурацию.

О пропуске можно сообщить в [Issues](https://github.com/fadeichev2121/antigravity-russian/issues): укажи ОС, версию, раздел и английскую фразу. На снимке скрой персональные данные.
