# Antigravity на русском — macOS

Локальный перевод **Antigravity Desktop 2.19.1**: окно менеджера агентов, настройки, подсказки и нативные меню macOS. Патч применяется к `/Applications/Antigravity.app` после сохранения резервной копии. **Отдельная Antigravity IDE не переводится.**

## Быстрый старт

1. Полностью закрой Antigravity через **Cmd+Q**.
2. Открой **Терминал** и выполни по очереди:

```bash
curl -fL https://raw.githubusercontent.com/fadeichev2121/antigravity-russian/main/install.sh -o antigravity_ru.sh
bash antigravity_ru.sh
```

3. Выбери **1 — Установить русский интерфейс**.
4. После завершения снова открой **Antigravity** из папки «Программы».

Установщик поддерживает только конкретную сборку **2.19.1**, которая уже имеет локальную ad-hoc подпись. **Официально подписанная сборка будет отклонена.** Снятие официальной подписи и изменение защиты приложения этим проектом не предусмотрены.

Если для изменения приложения нужны права администратора, меню само запросит их через sudo. Пароль вводится в терминале; символы при вводе не отображаются. Запускать скачанный файл целиком через sudo не нужно.

## Меню в терминале

```text
==== Русский интерфейс Antigravity для macOS ====
1) Установить русский интерфейс
2) Статус / совместимость
3) Откат
0) Выход
```

| Пункт | Что происходит |
| --- | --- |
| **1 — Установить** | Проверяются сборка, исходный архив и подпись; сохраняется резервная копия, затем применяется перевод. |
| **2 — Статус / совместимость** | Показываются версия, совместимость и состояние патча. Приложение не изменяется. |
| **3 — Откат** | Из резервной копии восстанавливаются исходные файлы и подпись. |
| **0 — Выход** | Установщик закрывается. |

Те же действия доступны без выбора пункта меню:

```bash
bash antigravity_ru.sh install
bash antigravity_ru.sh status
bash antigravity_ru.sh restore
bash antigravity_ru.sh --help
```

## Требования и совместимость

- **macOS**, на которой работает Antigravity Desktop **2.19.1**.
- Приложение в `/Applications/Antigravity.app` с поддерживаемым исходным архивом и **уже существующей ad-hoc подписью**.
- **Python 3.9 или новее**, доступный командой `python3`.
- Штатные утилиты macOS `codesign` и `ditto`.
- Интернет для загрузки установщика и файлов патча; место на диске для полной резервной копии приложения.

Проверяются **номер версии и SHA-256 исходного `app.asar`**, а также тип подписи. Совпадения номера версии недостаточно: другая сборка или уже изменённый архив могут оказаться несовместимыми. В этом случае установка останавливается до изменения файлов.

Windows, Linux, отдельная IDE и официально подписанные сборки этим установщиком не поддерживаются. Само приложение Antigravity и его исполняемые файлы в репозитории не распространяются.

## Резервная копия и откат

Перед изменением приложения установщик сохраняет его полную резервную копию. Копии и запись установки находятся здесь:

```text
~/Library/Application Support/antigravity-russian/state
```

Не удаляй эту папку, пока нужен автоматический откат. При запуске с `sudo` состояние сохраняется для исходного пользователя.

Чтобы снять перевод:

1. Полностью закрой Antigravity через **Cmd+Q**.
2. Выполни `bash antigravity_ru.sh restore` либо выбери **3 — Откат** в меню.
3. Снова открой Antigravity.

Если при откате нужны права администратора, меню само запросит пароль.

Восстанавливаются исходные файлы оболочки, `Info.plist` и подпись; резервные копии сохраняются. Пользовательские данные и история диалогов не удаляются. Если приложение обновилось или его файлы изменились после установки, откат остановится, чтобы не перезаписать новые изменения.

## Вопросы и ограничения

**Что переведено?**  
Словарь содержит **1142 записи**: названия и описания настроек, кнопки, переключатели, списки, подсказки, основные подписи окна и нативные меню. Новые серверные строки и экспериментальные экраны могут остаться на английском.

**Почему IDE осталась на английском?**  
Патч предназначен для Desktop — окна чатов и менеджера агентов. Отдельная Antigravity IDE в эту версию перевода не входит.

**Будут ли переводиться мои чаты и код?**  
Из перевода исключены сообщения, код, редактируемые поля и пользовательские названия. Переводчик использует локальный словарь, без сервиса машинного перевода. Язык ответов модели настраивается отдельно. Названия моделей, сервисов и команды сохраняются.

**Почему установщик отклонил приложение?**  
Поддерживается одна конкретная сборка. Установщик останавливается при другой версии, другом исходном архиве или официальной подписи. Не нужно отключать защиту macOS или снимать подпись ради применения этого патча.

**Патч уже стоит?**  
Выбери **2 — Статус / совместимость**. Запись состояния позволяет установщику распознать свою установку. Для копии, изменённой другим способом или старым локальным установщиком, совместимость может не подтвердиться; неизвестные изменения не перезаписываются.

**Что будет после обновления?**  
Обновление может удалить перевод. Автоматического повторного применения нет; новую сборку нужно адаптировать отдельно. Старый патч поверх несовместимой версии не устанавливается.

**Как сообщить о пропуске?**  
Создай [issue](https://github.com/fadeichev2121/antigravity-russian/issues) с версией, разделом и английской фразой. Если прикладываешь снимок экрана, скрой почту, имена, содержимое диалогов, идентификаторы и другие личные данные.

**Как проверялось?**  
Пользователь подтвердил работу перевода на своём Mac. Публичный установщик подготовлен отдельно; его установка и откат на других компьютерах ещё не подтверждены. Полный перевод всех возможных экранов не гарантируется.

## Для разработчиков

| Файл | Назначение |
| --- | --- |
| `install.sh` | Загрузка пакета, русское меню и выбор действия. |
| `macos/patch.py` | Совместимость, резервная копия, применение, состояние и откат. |
| `macos/ru.json` | Редактируемый словарь интерфейса. |
| `macos/ui-runtime.js` | Перевод известных текстовых узлов и подсказок с исключениями для пользовательского содержимого. |

Патч обновляет архив оболочки, контрольные суммы ASAR и подпись внешнего пакета. Используется существующая модель локальной подписи поддерживаемой сборки; переход с официальной подписи не реализован.
