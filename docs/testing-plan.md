# Автоматическая проверка Windows/Linux

Цель: проверить установщики на машинах GitHub, поскольку у пользователя есть только Mac. Используются стандартные бесплатные runner публичного репозитория: Windows x64/ARM64 и Ubuntu x64/ARM64. Для каждой платформы проверяются шесть релизов, всего 24 задания. Запуск ручной, не по расписанию.

Результат: **24 из 24 заданий прошли** 5 октября 2026 года. [GitHub Actions](https://github.com/fadeichev2121/antigravity-russian/actions/runs/37259045111), [сохранённый отчёт](verification/windows-linux-2.0.1.json). Проверен коммит `580028112313e03bb211b33a837b9b56ca7dce46` пакета 2.0.1; последующие изменения документации не меняют исполняемый код.

Выполненные сценарии:

- Получить исходный официальный пакет по URL из каталога совместимости, не выполнять vendor installer.
- Извлечь ASAR и основной бинарник во временную папку с пробелами и кириллицей; проверить исходные SHA-256 ASAR и Windows EXE, архитектуру ELF в Linux.
- Выполнить реальные платформенные launcher: статус, установка, повторная установка, обновление словаря, откат и повторный откат.
- Проверить точное восстановление исходных байтов, сохранение Windows EXE и Linux-владельца/режима доступа.
- Проверить отказ от перезаписи изменённого приложения и повреждённой резервной копии.
- Проверить загрузку пакета через отдельную копию standalone-launcher, установку и откат скачанным пакетом; дополнительно проверить bootstrap PowerShell 7.
- Сохранить только текстовые отчёты; оригинальные бинарники и пользовательские данные не публиковать.

Ограничения: само приложение не запускается; вход Google, чаты, отображение перевода и WSL не проверяются этим сценарием. Успех установщика не означает подтверждение всех экранов приложения. Текущий Mac и его приложение не изменяются.
