# Antigravity: версии и платформы

Цель: перевод установленного Antigravity Desktop 2.19.1 и пяти предыдущих релизов: 2.18.1, 2.17.0, 2.16.0, 2.15.1, 2.15.0. macOS Apple Silicon/Intel, Windows x64/ARM64 и Linux x64/ARM64.

Подход как в ранее опубликованном Claude-патче: проверка официальных исходных сборок по контрольным суммам, локальная замена интерфейсных файлов, сохранение исходных файлов, статус и откат через терминал. Общий переводчик обслуживает все платформы; операции с правами, подписью и расположением приложения остаются в платформенных установщиках.
