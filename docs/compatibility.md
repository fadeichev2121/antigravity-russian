# Совместимость пакета 2.0.0

Дата анализа: 5 октября 2026 года. Исходные приложения и установщики не запускались. Изменения установленных приложений не выполнялись.

## Источники и каталог

[Официальная загрузка](https://antigravity.google/download) и [каталог релизов](https://antigravity.google/releases). Публичный каталог, который использует официальная страница: [releases](https://antigravity-hub-auto-updater-974169037036.us-central1.run.app/releases).

Внутри одного релиза `app.asar` побайтно одинаков на всех платформах и архитектурах. Windows EXE различаются по архитектуре; выбор профиля проверяет обе суммы. Поэтому достаточно одного построения перевода для каждого из шести разных архивов, но идентичность источников сверена для всех 36 профилей.

## Различия платформ

**macOS.** Официальные DMG содержат приложение с подписью Google LLC, Team ID `EQHXZ8M8AV`, hardened runtime и исходными разрешениями. При согласии установщик меняет подпись только внешнего приложения, сохраняет исходные разрешения и добавляет `com.apple.security.cs.disable-library-validation`. Вложенные бинарники не меняются. Это решение по структуре подписи и [документации Apple](https://developer.apple.com/documentation/bundleresources/entitlements/com.apple.security.cs.disable-library-validation); успешный запуск переподписанной официальной сборки пока не подтверждён.

**Windows.** Официальные NSIS-пакеты содержат `Antigravity.exe` и `resources/app.asar`. Во всех 12 профилях Electron fuse `EnableEmbeddedAsarIntegrityValidation` выключен; EXE не требуется менять. PE-ресурс INTEGRITY исходный и сохраняется вместе со всем EXE. Поддерживаемые профили явно задают `integrity_update: false`. Выбор папки использует `InstallLocation` в реестре, затем стандартные пути; пользователь может задать `-AppPath`.

**Linux.** В официальных tar.gz папки `Antigravity-x64` / `Antigravity-arm64`, бинарник `antigravity` и `resources/app.asar`. Проверка встроенной целостности ASAR также выключена. Бинарник сохраняется; замена архива сохраняет владельца и режим доступа. Меню допускает пользовательскую папку или системную папку с повышением прав только для выбранного действия.

## Построение перевода

Для каждого релиза построен перевод пяти членов ASAR: `preload.js`, `menu.js`, `updater.js`, `main.js`, `tray.js`. Проверен синтаксис получившегося JavaScript. Для пяти старых версий отсутствующий API нативного контекстного меню пропускается только при известной исходной версии; перевод DOM работает через общий словарь.

В 2.16.0–2.19.1 меню приложения задаётся дважды, включая асинхронное обнаружение WSL. Перевод применяется при обоих вызовах. Поиск подменю `File` принимает и исходную, и русскую подпись, чтобы добавление WSL-пунктов не зависело от языка меню. Названия дистрибутивов не переводятся.

## Что проверено, а что остаётся

Выполнены анализ источников, сверка SHA-256 всех профилей, синтаксический разбор Python, Bash и пяти изменённых JS-файлов каждого релиза. Проведено чтение новых веток установки, обновления и отката. PowerShell-сценарий просмотрен вручную; PowerShell parser в среде разработки отсутствовал.

Не выполнялись запуск приложений, применение/снятие патча, переподпись реального приложения, проверка окон, переключение WSL или выполнение PowerShell-установщика. Совместимость по исходному коду не заменяет эти проверки. Новая версия подготовлена для самостоятельного тестирования пользователем.

## Сохранение исходных файлов

- macOS: полная копия при первой установке; при обновлении зарегистрированного перевода сохраняется исходная копия и четыре файла до обновления.
- Windows/Linux: транзакционная копия исходных и подготовленных файлов, журнал фаз операции и контрольные суммы. В Windows исходный EXE тоже учитывается в копии и состоянии, хотя не меняется.
- После штатного обновления принимается только полностью исходная известная сборка; предыдущая запись и резервные копии сохраняются. Откат не перезаписывает неизвестные файлы новой версии.
- При неизвестном архиве, повреждённой копии, ссылках/junction или несовпадении состояния автоматическая перезапись останавливается.
